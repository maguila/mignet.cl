# Repository Rules

## PHP Execution Rule
- **PHP Path Requirement**: Always use `C:\desarrollo\php\php.exe` (PHP 8.3.33) when running PHP commands, checking syntax, or starting local development servers.
- **System PATH Warning**: Do NOT use the raw `php` command as it invokes an older PHP 5.5 binary (`C:\desarrollo\labs\php\php55\php.exe`).
